# CLAUDE.md

Project-specific guidance for working in this repository.

## Documentation

- **When you need architecture or feature descriptions, consult [`docs/INDEX.md`](docs/INDEX.md) first.**
  It is the entry point to all architecture/feature docs — find the relevant headline,
  follow its path, and read that doc before exploring the code.
- **After implementing a feature, write a short doc for it** under `docs/` (create a new
  `.md` in the appropriate folder, or update the closest existing doc), **and add a
  one-line headline + path to `docs/INDEX.md`.** Keep docs small and logically scoped.
